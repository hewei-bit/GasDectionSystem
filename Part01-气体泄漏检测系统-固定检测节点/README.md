# 气体泄漏检测系统——固定检测节点（基于STM32F103，C语言）

本项目为气体泄漏检测系统的下位机固定监控节点，基于 STM32F103 平台，采用 C 语言开发。节点负责对环境气体浓度进行实时采集、处理和上传，是整个气体泄漏监控系统的重要组成部分。

## 主要功能

- 气体浓度采集：集成 MQ135 等气体传感器，实时采集环境气体浓度。
- 数据处理与上传：对采集数据进行滤波、处理，通过 LORA 无线通信模块上传至中继协调器。
- 多传感器支持：支持温湿度（DHT11）、加速度（MPU6050）、时钟（RTC）等多种外设扩展。
- 本地报警：支持蜂鸣器、LED 指示灯等本地声光报警。
- 按键交互：支持本地按键操作，便于调试和维护。
- OLED 显示：可选配 OLED 屏幕用于本地数据显示。
- 支持 UCOS-III 实时操作系统，任务调度高效可靠。

## 依赖环境

- 硬件平台：STM32F103 系列单片机
- 开发环境：Keil uVision 5 或 MDK-ARM
- 编程语言：C 语言（C99 及以上）
- UCOS-III 实时操作系统
- 推荐调试器：J-Link、ST-Link

## 编译与烧录

1. 使用 Keil uVision 打开 `USER/Template.uvprojx` 工程文件。
2. 配置目标芯片型号（如 STM32F103C8T6）。
3. 编译工程，生成固件。
4. 使用 J-Link 或 ST-Link 下载固件至开发板。

## 主要模块说明

- **气体传感器（MQ135）**：采集空气中有害气体浓度。
- **温湿度传感器（DHT11）**：采集环境温湿度。
- **加速度传感器（MPU6050）**：采集节点姿态信息。
- **LORA 通信**：实现节点与中继/上位机的数据无线传输。
- **本地报警**：蜂鸣器、LED 实现本地声光报警。
- **OLED 显示**：本地数据显示与菜单操作。
- **UCOS-III**：多任务调度，提升系统实时性与可靠性。
