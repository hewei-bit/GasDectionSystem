# 气体泄漏检测系统——中继协调节点（基于STM32F103，C语言）

本项目为气体泄漏检测系统的下位机中继协调节点，基于 STM32F103 平台，采用 C 语言开发。中继节点负责采集多种传感器数据、协调下位机节点、数据本地存储与转发，是系统数据汇聚与上传的核心。

## 主要功能

- 多传感器数据采集：支持 DHT11（温湿度）、TDLAS（气体浓度，串口）、MQ135、MQ4 等多种传感器。
- 数据本地存储：通过 FATFS 文件系统将数据以 txt 格式存储于 SD 卡。
- LORA 无线转发：通过 LORA 模块将数据转发至上位机，实现远距离无线通信。
- 多任务调度：基于 UCOS-III 实时操作系统，采用信号量、消息队列、互斥锁、事件标志组等内核对象实现任务间高效协作。
- 本地显示与报警：支持 OLED/LCD 显示、LED 指示、蜂鸣器报警。
- 看门狗保护：提升系统可靠性。
- 支持上位机数据问询与响应。
- 支持多节点数据管理与协调。

## 依赖环境

- 硬件平台：STM32F103系列单片机
- 开发环境：Keil uVision 5 或 MDK-ARM
- 编程语言：C语言（C99及以上）
- UCOS-III实时操作系统
- FATFS文件系统
- 推荐调试器：J-Link、ST-Link

## 编译与烧录

1. 使用 Keil uVision 打开 `USER/Template.uvprojx` 工程文件。
2. 配置目标芯片型号（如 STM32F103ZET6）。
3. 编译工程，生成固件。
4. 使用 J-Link 或 ST-Link 下载固件至开发板。

## 主要模块说明

- **多任务调度**：每个硬件模块由独立任务管理，任务间通过信号量、消息队列、互斥锁等内核对象协作。
- **传感器采集**：DHT11、TDLAS、MQ135、MQ4等多种气体与环境传感器。
- **本地存储**：FATFS文件系统，SD卡数据存储。
- **LORA转发**：无线数据转发至上位机。
- **本地显示与报警**：OLED/LCD、LED、蜂鸣器。
- **看门狗**：系统自恢复。
- **上位机通信**：支持数据问询与响应。
