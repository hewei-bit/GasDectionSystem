# Part04-输气站场气体泄漏监测系统上位机（基于Qt/C++）

本项目为输气站场气体泄漏监测系统的上位机软件，基于 Qt 平台，采用 C++ 语言开发。主要用于对气体泄漏检测终端的数据进行采集、显示、存储和管理，实现对输气站场气体泄漏的实时监控与报警。

## 主要功能

- 串口通信：与下位机节点进行数据交互，实时接收气体检测数据。
- 数据可视化：支持气体浓度、报警状态等信息的图表化展示。
- 数据存储：支持将检测数据存入本地数据库，便于历史数据查询与分析。
- 多节点管理：支持多检测节点的统一管理与状态监控。
- 报警提示：当检测到气体浓度超标时，自动弹窗报警并记录事件。
- 配置管理：支持串口、数据库等参数的灵活配置。

## 依赖环境

- Qt 5.x 或 Qt 6.x（建议使用 Qt Creator 进行开发和编译）
- C++11 及以上标准
- 数据库：支持 SQLite（默认），可扩展为 MySQL、PostgreSQL 等
- 推荐操作系统：Windows 10/11

## 编译与运行

1. 安装 Qt 开发环境（Qt Creator）。
2. 使用 Qt Creator 打开 `GasLeakMonitor.pro` 工程文件。
3. 配置合适的编译器和 Qt 版本。
4. 编译并运行项目。
5. 运行前可在 UI 中设置串口参数和数据库路径。

## 主要模块说明

- **串口通信（serial/）**：负责与下位机节点的数据交互。
- **数据可视化（qcustomplot/）**：基于 QCustomPlot 实现数据曲线、柱状图等展示。
- **数据库管理（database/）**：实现数据的本地存储与查询。
- **主界面（mainwidget/）**：集成各功能模块，提供友好的用户操作界面。
- **定时与多线程（timethread/）**：实现定时采集、数据刷新等功能。
